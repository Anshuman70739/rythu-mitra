# Rythu Mitra

A farmer-focused web experience for Telangana.

## Working website

The Monsoon landing page and its supporting files are maintained on [Rythumitra-SHX](https://github.com/Anshuman70739/rythu-mitra/tree/Rythumitra-SHX).

## Repository branches

- Rythumitra-SHX — working landing page.
- Rythumitra-CD — development branch.
- Rythumitra-CD-test — testing branch.
- RythuMitra — clean starting point for the main project.

The project is being kept simple while the working landing page is finalized. Features that depend on external services or unverified models should not be described as live.
