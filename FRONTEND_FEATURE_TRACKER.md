# Feature tracker — requested frontend specification

Statuses: **implemented** = UI behavior exists in source; **integration-tested** = exercised against the running backend; **blocked** = depends on missing provider/model/credential or missing backend function; **follow-up** = partially represented or requires deeper workflow/security work; **planned** = not yet implemented. This file avoids treating source presence as proof of end-to-end integration.

| ID | Feature(s) in the request | Status | What this build does / remaining limitation |
